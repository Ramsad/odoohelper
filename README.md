# Odoo Helper

This repository contains a simple static HTML-based helper page for Odoo-related tasks.

## Contents

- `index.html` — the main application page

## Usage

1. Open `index.html` in your browser.
2. If needed, serve the project with a simple local web server.

## Notes

This project is currently a front-end HTML-only repository and does not require a build step or package installation.
